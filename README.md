# MLB Batting Analysis – Season 2022 ⚾📊

## 📌 Project Overview
This project analyzes offensive performance of MLB players during the 2022 season using batting statistics.

The goal is to explore player efficiency, compare performance across positions, and identify standout or potentially undervalued players through exploratory data analysis (EDA).

## 📂 Dataset
- Source: Public MLB batting statistics dataset (CSV)
- Season: 2022
- Scope: MLB batters with sufficient playing time

## 🎯 Objectives
- Analyze key batting metrics (AVG, OBP, SLG, OPS)
- Compare player performance by position
- Identify top performers and outliers
- Explore relationships between efficiency and opportunities

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
